### API Naming Conventions

- **Modules**: directory name is plural kebab-case matching the resource (`posts/`, `post-requests/`)
- **Files**: `<feature>.controller.ts`, `<feature>.service.ts`, `<feature>.repository.ts`, `<feature>.module.ts`
- **DTOs**: `<action>-<resource>.dto.ts` — e.g., `create-post.dto.ts`, `list-posts.dto.ts`
- **Entities**: `<resource>.entity.ts` — Swagger response type classes decorated with `@ApiProperty`
- **Nested features**: placed as a subdirectory inside the parent module (e.g., `posts/comments/`)
- **Path alias**: `@/` maps to `src/` throughout the API codebase

### Web Naming Conventions

- **Route groups**: parenthesised directory names — `(app)`, `(auth)`, `(protected)` — do not appear in the URL
- **Dynamic segments**: bracket notation — `[id]`, `[shortCode]`
- **Page files**: always `page.tsx`; layout files always `layout.tsx`
- **Components**: kebab-case filenames matching the exported PascalCase component — `post-card.tsx` exports `PostCard`
- **Hooks**: `use-<name>.ts` (kebab-case)
- **Stores**: `use<Name>Store` exported from `lib/store.ts`
- **Generated files**: placed under `src/lib/api/generated/` — never edited manually; regenerated with `pnpm api:sync`
- **Path aliases**: `@/` maps to the `apps/web/` root; `@/src/` maps to `apps/web/src/`
