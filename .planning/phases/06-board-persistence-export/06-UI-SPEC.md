## Interaction States

### Export PNG

1. User clicks "Export" button → dropdown opens
2. User clicks "Export PNG" → dropdown closes → `exportToBlob()` called → file download triggered with filename `unishare-board-{slug}.png` → `toast.success('Board exported as PNG')`
3. On failure: `toast.error('Export failed — try again')`

### Export PDF

1. User clicks "Export PDF" → dropdown closes → PDF export triggered → file download with `unishare-board-{slug}.pdf` → `toast.success('Board exported as PDF')`
2. On failure: `toast.error('Export failed — try again')`

### Post to UniShare (authenticated user)

1. User clicks "Post to UniShare" → dropdown closes → PNG exported → stored in `sessionStorage['pending-board-export']` → `/posts/new` opens in new tab → `toast.success('Opening post editor...')`
2. New tab `/posts/new` mounts → reads sessionStorage → pre-attaches PNG in FILES step → clears sessionStorage key

### Post to UniShare (guest user)

1. Menu item rendered with `disabled` prop → Tooltip shows "Sign in to post to UniShare" on hover/focus → click is a no-op (Radix disabled behavior)

### Race condition retry (behavioral, no visual change)

1. `POST /api/rooms/:slug/join` returns 401 or 403 → wait 800ms → retry once
2. Retry succeeds → proceed to joined state (no visible flicker; loading overlay stays shown throughout)
3. Retry fails OR original error is 404 → set `joinState('not-found')` → show error page

## Accessibility

- Export dropdown trigger: `aria-label="Export board options"` (button has icon + text label, aria-label provides full context for screen readers)
- Disabled "Post to UniShare" item: `aria-disabled="true"` (Radix DropdownMenuItem disabled prop sets this automatically)
- Tooltip on disabled item: `role="tooltip"`, referenced via `aria-describedby` (shadcn Tooltip handles this)
- File download: triggered via anchor click or `URL.createObjectURL` — no additional ARIA needed
- Toast notifications: sonner renders with `role="status"` / `aria-live="polite"` by default
