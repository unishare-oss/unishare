## Spacing Scale

Multiples of 4. Existing canvas header uses `h-12` (48px), `px-4` (16px), `gap-2` (8px), `gap-1` (4px) — all on-scale.

| Token | Value | Usage in This Phase                                       |
| ----- | ----- | --------------------------------------------------------- |
| xs    | 4px   | Cursor arrow/pill gap; icon gaps                          |
| sm    | 8px   | Pill horizontal padding (px-2); avatar stack gap override |
| md    | 16px  | Header section padding (carries from Phase 4)             |
| lg    | 24px  | Dropdown list item padding vertical                       |
| xl    | 32px  | —                                                         |
| 2xl   | 48px  | Canvas header height (h-12 = 48px, existing)              |
| 3xl   | 64px  | —                                                         |

**Exceptions:**

- Avatar stack overlap: `ml-[-6px]` on 2nd+ avatars — intentional -6px overlap to create stacked appearance within the 8-point grid boundary
- Presence avatar size: **24×24px** (w-6 h-6) — maintains 8-point grid; touch target not applicable (avatars open a dropdown, not direct action)
- Cursor arrow: **16×20px** SVG — designed for legibility without occluding canvas content; off standard scale but visually calibrated

## Typography

Carries Phase 4 declarations. Phase 5 adds two micro-typography tokens for presence UI.

| Role        | Size | Weight         | Line Height | Where Used                           |
| ----------- | ---- | -------------- | ----------- | ------------------------------------ |
| Body        | 14px | 400 (regular)  | 1.5         | Dropdown participant name            |
| Label       | 12px | 500 (medium)   | 1           | Avatar initials; overflow badge "+N" |
| Cursor pill | 11px | 500 (medium)   | 1           | Name tag below cursor tip            |
| Heading     | 20px | 600 (semibold) | 1.2         | Not used in this phase               |

**Cursor pill detail:** `text-[11px] font-medium leading-none` — smallest legible size at 1× DPR on a canvas background. Not smaller — 10px and below becomes unreadable at standard viewing distance.

**Initials extraction rule:** First character of first word + first character of last word (if present), both uppercase. Single-word names: first two characters. Anonymous guests: first two characters of their generated display name (e.g., "SleepyOtter" → "SL").

### 60 / 30 / 10 Split

| Role      | Value                                     | %   | Where                                                     |
| --------- | ----------------------------------------- | --- | --------------------------------------------------------- |
| Dominant  | `#f7f3ee` (background) + `#ffffff` (card) | 60% | Canvas surface, header                                    |
| Secondary | `#e2dad0` (border), `#f7f3ee` (muted)     | 30% | Dividers, muted text, avatar ring                         |
| Accent    | Presence colors (see palette below)       | 10% | Avatar fills, cursor arrow fills, cursor pill backgrounds |

**Accent reserved for:**

1. Presence avatar background fill
2. Remote cursor arrow SVG fill
3. Remote cursor name-pill background
4. Participant color dot in dropdown list

Accent is **NOT** used for: button states, focus rings, hover states, links, form elements — those use `--primary` (amber) per existing Phase 4 contract.

### Presence Color Palette

10 distinct accessible colors. Deterministic hash of `user.id` / anonymous session ID → palette index. Same person = same color across sessions.

```typescript
export const PRESENCE_COLORS = [
  '#E03131', // [0] red
  '#2F9E44', // [1] forest green
  '#1971C2', // [2] ocean blue
  '#7048E8', // [3] violet
  '#0C8599', // [4] teal
  '#C2255C', // [5] berry
  '#364FC7', // [6] indigo
  '#D9480F', // [7] burnt orange
  '#5C7CFA', // [8] periwinkle
  '#099268', // [9] jade
] as const
```

**Palette constraints (all satisfied):**

- ✅ Excludes UniShare amber (`#d97706` family) — no brand clash
- ✅ Excludes neutral grays — no blend with canvas/header chrome
- ✅ All 10 pass WCAG AA 4.5:1 contrast with white text (`#ffffff`)
- ✅ Visually distinct at 24×24px avatar size and 16px cursor arrow size
- ✅ Readable on both Excalidraw light (`#ffffff`) and dark (`#1e1e2e`) canvas backgrounds

## Component Inventory

### 1. `CursorOverlay` (NEW — `apps/web/src/components/canvas/cursor-overlay.tsx`)

**Role:** Absolute-positioned container layered over `<main>` (the Excalidraw wrapper). Renders one `RemoteCursor` per remote participant.

**Layout contract:**

```
position: absolute
inset: 0                        /* covers full canvas main area */
pointer-events: none            /* MUST NOT block Excalidraw mouse events */
overflow: hidden                /* clip cursors at canvas boundary — no header bleed */
z-index: 10                     /* above Excalidraw toolbar chrome, below modals */
```

**Behavior:**

- Re-renders when `remoteCursors` map updates (socket `cursor-move` event)
- Re-renders when `excalidrawAPI.onScrollChange()` fires (pan/zoom repositioning)
- Cursors outside computed `[0, containerWidth] × [0, containerHeight]` bounds are **not rendered** (conditional `return null` in `RemoteCursor`)

**Canvas page wiring:**

```tsx
// In CanvasInner, inside <main className="relative flex-1">:
<main className="relative flex-1">
  <ExcalidrawWrapper />
  <CursorOverlay /> {/* layered here, after ExcalidrawWrapper */}
</main>
```

### 2. `RemoteCursor` (NEW — `apps/web/src/components/canvas/remote-cursor.tsx`)

**Role:** One remote participant's cursor: filled arrow SVG + rounded pill name tag.

**Visual spec:**

```
┌─ Cursor Arrow (SVG) ──────────────┐
│  Size: 16×20px                    │
│  Fill: presenceColor[colorIndex]  │
│  Stroke: #ffffff, 1.5px           │
│  Shape: standard cursor arrow     │
│         pointing top-left         │
│  No drop shadow                   │
└───────────────────────────────────┘
         ↘ (anchored below-right of tip)
┌─ Name Pill ───────────────────────┐
│  bg: presenceColor[colorIndex]    │
│  text: #ffffff                    │
│  font: 11px / 500 / leading-none  │
│  padding: px-2 py-0.5 (8px/2px)  │
│  border-radius: rounded-full      │
│  white-space: nowrap              │
│  No drop shadow                   │
└───────────────────────────────────┘
```

**Positioning:**

- Root element: `position: absolute`, `left: {x}px`, `top: {y}px`
- x/y are computed from `sceneToOverlay()` conversion using `excalidrawAPI.getAppState()`
- Arrow tip aligns to (x, y) — pill is offset `top: 18px, left: 12px` relative to the arrow root
- Entire component: `pointer-events: none`

**Visibility rule:**

- `if (x < 0 || x > containerWidth || y < 0 || y > containerHeight) return null`
- Silently hidden — no edge indicator

**SVG arrow shape** (exact path — standard cursor arrow, pointing up-left):

```svg
<svg width="16" height="20" viewBox="0 0 16 20" fill="none">
  <path
    d="M2 2L2 16L6 12L9 18L11 17L8 11L13.5 11L2 2Z"
    fill="{presenceColor}"
    stroke="white"
    strokeWidth="1.5"
    strokeLinejoin="round"
    strokeLinecap="round"
  />
</svg>
```

### 3. `ParticipantAvatars` (NEW — added to `apps/web/src/components/canvas/canvas-header.tsx`)

**Role:** Stacked initials avatars in canvas header, between logo and "Copy link" button. Opens dropdown listing all participants.

**Avatar stack layout:**

```
[A] [B] [C] [+2]   ← max 3 visible + overflow badge
  ↑overlapping by 6px (ml-[-6px] on 2nd+)
```

**Single avatar spec:**

```
size: w-6 h-6 (24×24px)
shape: rounded-full
bg: presenceColor[colorIndex]  ← solid fill
text: 11px / 500 / leading-none / text-white / uppercase
border: ring-2 ring-background   ← 2px white ring for separation in stack
cursor: default (not pointer — click target is the stack group, not individual avatars)
```

**Overflow badge spec ("+N"):**

```
size: w-6 h-6 (24×24px)
shape: rounded-full
bg: var(--muted)            ← #f7f3ee
text: 11px / 500 / text-muted-foreground / leading-none
border: ring-2 ring-background
content: "+{count}" where count = total - 3
```

**Stack group:**

```
display: flex
align-items: center
cursor: pointer             ← whole group is the trigger
```

**Dropdown trigger:** The entire avatar stack group is wrapped in `<DropdownMenu>` trigger. Clicking anywhere in the stack (any avatar or overflow badge) opens the dropdown.

**Dropdown content spec:**

```
width: w-56 (224px)
align: end (right-aligned to trigger)
sideOffset: 8px
```

**Dropdown item layout (one per participant):**

```
┌────────────────────────────────────┐
│  ● [12px color dot]  Name   (you)  │
└────────────────────────────────────┘
  px-3 py-2   flex items-center gap-2
```

- Color dot: `w-3 h-3 rounded-full bg-[presenceColor]`
- Name: `text-sm text-foreground flex-1`
- "(you)" suffix: `text-xs text-muted-foreground ml-1` — only on current user's entry
- No click action on items — dropdown is display-only, not interactive

**shadcn component used:** `<DropdownMenu>` from `@/components/ui/dropdown-menu` (already installed)

**Header wiring:**

```tsx
// canvas-header.tsx receives participants via useCollab()
// Insertion point: between <Link> (logo) and <Button> (copy link)
<header className="relative z-10 flex h-12 items-center justify-between border-b border-border bg-card px-4">
  <Link ...>  {/* logo — unchanged */}
  <ParticipantAvatars participants={participants} currentSocketId={socketId} />  {/* NEW */}
  <Button ...> Copy link </Button>  {/* unchanged */}
</header>
```

**When only 1 participant (self alone):** Render single avatar (the current user) with no dropdown trigger (or dropdown with just the self entry). Stack group still renders — never hidden.

**Visibility when ≤3 participants:** No overflow badge. Show all avatars directly.

**Visibility when >3 participants:** Show first 3 avatars + "+N" badge (N = total - 3). All participants shown in dropdown regardless.

## Layout & Z-Index Stack

Phase 5 adds two new layers to the canvas page:

```
z-index  Layer
──────── ──────────────────────────────────────
  30     Loading/error overlays (existing, fixed)
  10     CursorOverlay (absolute, inside <main>)
  10     CanvasHeader (existing, relative z-10)
   0     ExcalidrawWrapper (fills <main>)
```

**Canvas page structure (after Phase 5):**

```tsx
<div className="flex h-screen flex-col">
  <CanvasHeader /> {/* h-12, relative z-10 */}
  <main className="relative flex-1 overflow-hidden">
    <ExcalidrawWrapper /> {/* fills flex-1 */}

  </main>

```

`overflow-hidden` on `<main>` is required — clips cursor overlays at canvas boundary, preventing header bleed.

## Interaction Contracts

### Cursor Movement

| Event                        | Contract                                                                                                   |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Pointer moves over canvas    | Throttled `cursor-move` emit (max 30/sec, `useRef` timestamp gate)                                         |
| Pointer leaves canvas        | No explicit leave event — cursor stays at last known position                                              |
| No movement for any duration | Cursor stays visible at last known position (no fade, no timeout)                                          |
| Remote cursor-move received  | `remoteCursors` Map updated → React re-render positions cursor                                             |
| Canvas pan or zoom           | `onScrollChange` fires → `scrollTick` state increments → overlay re-renders, cursor positions recalculated |

### Participant Joins

| Event                 | Contract                                                                                        |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| Self joins room       | Receives `participant-list` (full current list) from server                                     |
| Another user joins    | Receives `participant-joined` `{ socketId, name, colorIndex }` → avatar appears in header stack |
| No toast/notification | Silent — avatar just appears                                                                    |

### Participant Leaves

| Event                    | Contract                                                                                                   |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Another user disconnects | Receives `participant-left` `{ socketId }` → avatar removed from header stack, cursor removed from overlay |
| No toast/notification    | Silent — avatar just disappears                                                                            |
| Removal timing           | Immediate on socket disconnect (within 1s)                                                                 |

### Participant Dropdown

| Interaction            | Contract                                                |
| ---------------------- | ------------------------------------------------------- |
| Click avatar stack     | Opens dropdown                                          |
| Click anywhere outside | Closes dropdown (Radix `DropdownMenu` default)          |
| Escape key             | Closes dropdown (Radix `DropdownMenu` default)          |
| Items                  | Display-only. No pointer cursor. No hover state action. |

## Copywriting Contract

| Element                                 | Copy                                             | Source                                |
| --------------------------------------- | ------------------------------------------------ | ------------------------------------- |
| "(you)" suffix                          | `(you)`                                          | CONTEXT.md: confirmed                 |
| Participant dropdown trigger aria-label | `"Participants in this room"`                    | Claude's discretion                   |
| Dropdown item aria-label (self)         | `"{name} (you)"`                                 | Claude's discretion                   |
| Cursor aria-label (hidden from AT)      | Not announced — overlay has `aria-hidden="true"` | Accessibility: cursors are decorative |
| Copy link button                        | `"Copy link"`                                    | Phase 4 carry-forward (unchanged)     |
| Toast on copy success                   | `"Link copied"`                                  | Phase 4 carry-forward (unchanged)     |

**Empty states:**

| Scenario                                 | Copy                                                                                                                       |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Only self in room (participant dropdown) | Shows self entry only: `"{your name} (you)"` — no "nobody else here" message needed; avatar stack naturally shows 1 avatar |
| Cursors — no others connected            | No overlay rendered (empty `remoteCursors` map) — no empty state message                                                   |

**Error states:**

| Scenario                | Copy                                                                                                                                                                          |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Presence errors         | Degraded silently — if `cursor-move` events stop or `participant-joined` is missed, the UI reflects whatever state it last received. No error toast for presence degradation. |
| Socket connection error | Handled by existing Phase 4 connection status logic (toast via `sonner` on disconnect) — no new copy needed                                                                   |

**Destructive actions:** None in Phase 5.

## Accessibility Contract

| Concern                           | Contract                                                                                     |
| --------------------------------- | -------------------------------------------------------------------------------------------- |
| Cursor overlay                    | `aria-hidden="true"` on the overlay container — cursors are decorative, not interactive      |
| Participant dropdown              | Radix `DropdownMenu` provides full keyboard nav and ARIA roles automatically                 |
| Avatar stack trigger              | `aria-label="Participants in this room"` on the trigger wrapper                              |
| Color as sole differentiator      | Participant names always visible in pill + dropdown — color is additive, not sole identifier |
| Focus management                  | No custom focus logic needed — Radix handles dropdown focus trap                             |
| `pointer-events: none` on overlay | Ensures Excalidraw remains fully keyboard and mouse accessible                               |
