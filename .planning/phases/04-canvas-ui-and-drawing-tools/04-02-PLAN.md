**Exports:**

- `CollabProvider` — React context provider component
- `useCollab` — Hook to consume the context

**CollabProvider props:**

```typescript
interface CollabProviderProps {
  slug: string
  children: React.ReactNode
}
```

**Context value type:**

```typescript
type ConnectionStatus = 'connecting' | 'connected' | 'disconnected'

interface CollabContextValue {
  ydoc: Y.Doc
  yElements: Y.Array<unknown>
  connectionStatus: ConnectionStatus
  excalidrawAPI: ExcalidrawImperativeAPI | null
  setExcalidrawAPI: (api: ExcalidrawImperativeAPI | null) => void
  initialElements: unknown[] | null
}
```

Note: `ExcalidrawImperativeAPI` type import should use `import type { ExcalidrawImperativeAPI } from '@excalidraw/excalidraw/types'`. If this path does not resolve, use `any` with a `// TODO: type properly` comment — Plan 03 will verify the exact import path.

**Implementation logic (in a useEffect with slug dependency):**

1. Create `Y.Doc` instance and get `Y.Array` via `ydoc.getArray('elements')`.

2. Create socket.io connection:

   ```typescript
   const apiUrl = process.env.NEXT_PUBLIC_API_URL ?? 'http://localhost:3001'
   const socket = io(`${apiUrl}/collab`, {
     withCredentials: true,
     autoConnect: false,
   })
   ```

3. Set up socket event handlers:
   - `socket.on('connect', () => { socket.emit('join-room', slug) })`
   - `socket.on('room-joined', ({ state }: { slug: string; state: ArrayBuffer }) => { ... })`:
     - Call `Y.applyUpdate(ydoc, new Uint8Array(state), 'init')`
     - Read `yElements.toArray()` and store as `initialElements` in state
     - Set `connectionStatus` to `'connected'`
   - `socket.on('yjs-update', (data: ArrayBuffer) => { Y.applyUpdate(ydoc, new Uint8Array(data), 'remote') })`
   - `socket.on('disconnect', () => { setConnectionStatus('disconnected') })`
   - `socket.on('connect', () => { ... })` — on reconnect (not first connect), update status. Use a ref `hasJoined` to distinguish first connect from reconnect. On reconnect, re-emit `'join-room'`.

4. Set up Yjs update handler — relay local changes to server:

   ```typescript
   ydoc.on('update', (update: Uint8Array, origin: unknown) => {
     if (origin === 'remote' || origin === 'init') return
     socket.emit('yjs-update', update)
   })
   ```

5. Set up Y.Array observer for remote updates — call excalidrawAPI.updateScene:

   ```typescript
   yElements.observe(() => {
     // Only update Excalidraw when the change came from a remote source
     // The excalidrawAPI ref is set by Plan 03's ExcalidrawWrapper
     // Use CaptureUpdateAction.NEVER to prevent remote changes entering undo stack
   })
   ```

   NOTE: The observer will import `CaptureUpdateAction` from `@excalidraw/excalidraw`. If this import fails at build time (because Excalidraw is browser-only), guard it with a dynamic import or defer the observer setup to the ExcalidrawWrapper in Plan 03. For now, set up the observer but guard the `excalidrawAPI?.updateScene()` call behind a null check.

6. Connect the socket: `socket.connect()`

7. Cleanup on unmount: `socket.disconnect()`, `ydoc.destroy()`

**Connection state toast notifications:**

Import `toast` from `sonner`. In the disconnect handler:

```typescript
toast.error('Connection lost — reconnecting...', { id: 'collab-status', duration: Infinity })
```

In the reconnect handler (connect event when `hasJoined.current === true`):

```typescript
toast.dismiss('collab-status')
toast.success('Reconnected', { duration: 2000 })
```

**Context provider value:**

```typescript
const value: CollabContextValue = {
  ydoc,
  yElements,
  connectionStatus,
  excalidrawAPI,
  setExcalidrawAPI,
  initialElements,
}
```

**useCollab hook:**

```typescript
export function useCollab() {
  const context = useContext(CollabContext)
  if (!context) throw new Error('useCollab must be used within a CollabProvider')
  return context
}
```
