# Phase 4 — UI Design Contract

> Visual and interaction contract for the Canvas UI & Drawing Tools phase. Generated by gsd-ui-researcher. Covers only the 3 custom surfaces in this phase — the Excalidraw canvas itself provides its own UI and is not contracted here.

**Custom surfaces in scope:**

1. Canvas header bar (thin bar above Excalidraw)
2. Loading overlay (full-screen, shown while connecting)
3. Error page (shown when room slug is not found)

**Out of scope for this contract:**

- Excalidraw toolbar, canvas, drawing tools — Excalidraw owns these
- Presence cursors and participant list — Phase 5
- Export controls — Phase 6

## Surface Specifications

### Surface 1: Canvas Header Bar

**Layout:** Fixed 48px-tall bar. Flex row, `items-center`, `justify-between`. Horizontal padding 16px. Background: `var(--card)`. Bottom border: 1px solid `var(--border)`.

**Left slot:** UniShare wordmark or logo mark (existing asset from the app shell). Wrapped in a Next.js `<Link href="/feed">` — functions as "back to feed" navigation. No label text — logo only. Touch target: 44px height minimum.

**Right slot:** "Copy room link" button. shadcn `<Button variant="default" size="sm">`. Label: "Copy link". Uses `ClipboardCopy` icon from lucide-react at 16px, placed left of the label text, gap 4px. On click: copies `window.location.href` to clipboard, shows sonner `toast.success("Link copied")` (auto-dismisses 2s). No confirmation modal.

**Separator:** 1px border-bottom using `var(--border)` only. No shadow.

**Z-index:** `z-10` — sits above the Excalidraw canvas iframe layer.

---

### Surface 2: Loading Overlay

**Trigger:** Mounted immediately when the canvas page loads, unmounted only after `connectionStatus === 'connected'` (socket connected AND `room-joined` received). Excalidraw does not mount while this overlay is visible.

**Layout:** Fixed position, full viewport (`inset-0`). Background: `var(--background)` at 100% opacity — fully opaque, not a translucent modal. `z-20` (above header). Flex column, `items-center`, `justify-center`, gap 24px.

**Content:**

- Spinner: shadcn `Skeleton` component or a simple CSS `animate-spin` circle (24px diameter, border-2, border-t-transparent, border color `var(--primary)`). No third-party spinner library.
- Status text: "Connecting to room..." — 14px semibold, `var(--foreground)`.
- No cancel button, no timeout UI (socket.io-client handles reconnection internally).

**Transition:** When `connectionStatus` flips to `'connected'`, remove the overlay immediately (no fade — Excalidraw mounting itself provides the visual transition).

---

### Surface 3: Error Page (Room Not Found)

**Trigger:** Rendered when `POST /api/rooms/:slug/join` returns HTTP 404. Replaces the loading overlay. No socket connection is attempted.

**Layout:** Full viewport. Background: `var(--background)`. Flex column, `items-center`, `justify-center`, gap 16px. Top margin from center: asymmetric — content sits at visual center (no offset needed).

**Content stack (top to bottom):**

1. Icon: `DoorClosed` from lucide-react, 48px, color `var(--muted-foreground)`.
2. Heading: "Room not found" — 20px semibold, `var(--foreground)`.
3. Body: "This room doesn't exist or the link may have expired." — 14px regular, `var(--muted-foreground)`, max-width 320px, text-center.
4. CTA button: shadcn `<Button variant="default">` — label "Back to UniShare". Links to `/feed` via Next.js `<Link>`. Width: auto (hug content).

**No retry button** — a 404 is definitive; retrying the same invalid slug serves no purpose.

## Interaction Contract

### Copy Room Link

1. User clicks "Copy link" button in header.
2. `navigator.clipboard.writeText(window.location.href)` executes.
3. `toast.success("Link copied")` fires via sonner (2s auto-dismiss).
4. No icon change, no button state change — toast is the sole feedback.
5. If clipboard API unavailable (non-HTTPS context): `toast.error("Could not copy link — copy it from the address bar")`.

### Connection Lost / Reconnected

1. Socket `disconnect` event fires.
2. `toast.error("Connection lost — reconnecting...", { id: 'collab-status', duration: Infinity })` — persists until resolved.
3. Canvas remains interactive (local-only edits continue).
4. Socket reconnects (socket.io-client exponential backoff).
5. Socket `connect` event fires.
6. `toast.dismiss('collab-status')` then `toast.success("Reconnected", { duration: 2000 })`.

### Theme Mapping to Excalidraw

1. `useTheme()` from `next-themes` returns the active theme string (e.g. `'theme-catppuccin-mocha'`).
2. Check against `DARK_THEMES` list — if match, pass `theme="dark"` to Excalidraw; else `theme="light"`.
3. Container `div` wrapping `<Excalidraw>` has inline style: `{ '--color-primary': 'var(--primary)' }` (typed as `React.CSSProperties`).
4. On theme change (user toggles theme elsewhere in the app), the Excalidraw `theme` prop and CSS variable update reactively.

### Excalidraw UI Suppression

The following Excalidraw UI elements are hidden to avoid collision with the custom CollabProvider:

- Native collab trigger: `renderTopRightUI={() => null}`
- In-canvas theme toggle: `UIOptions={{ canvasActions: { toggleTheme: false } }}`
- All other `UIOptions` and `canvasActions` use Excalidraw defaults.

## Accessibility

- Header logo link: `aria-label="Back to UniShare feed"` on the `<Link>` wrapping the logo.
- "Copy link" button: standard button role; no additional aria needed (visible label present).
- Loading overlay: `role="status"` `aria-live="polite"` `aria-label="Connecting to collaboration room"` on the overlay container.
- Error page: standard heading hierarchy (`<h1>` for "Room not found"). CTA is a native `<a>` via `<Link>` — no role override needed.
- Focus trap: not needed for loading overlay (it is opaque but not a dialog; no interactive elements to trap focus within).
- Color contrast: all text uses `var(--foreground)` or `var(--muted-foreground)` on `var(--background)` — contrast ratios established by the existing theme system, verified for the default UniShare theme (dark stone on warm cream).
