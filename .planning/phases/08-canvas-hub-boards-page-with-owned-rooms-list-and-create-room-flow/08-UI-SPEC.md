## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage                                                                |
| ----- | ----- | -------------------------------------------------------------------- |
| xs    | 4px   | Icon gaps, inline padding (gap-1)                                    |
| sm    | 8px   | Compact element spacing, gap between badge and meta (gap-2)          |
| md    | 16px  | Card internal padding (p-4), PageHeader horizontal padding (px-6)    |
| lg    | 24px  | PageHeader padding (px-6 py-4 = 24px horizontal), section gap        |
| xl    | 32px  | Grid gap between room cards (gap-4 gives 16px; grid outer pad 32px)  |
| 2xl   | 48px  | Empty state vertical padding (py-12 = 48px above/below illustration) |
| 3xl   | 64px  | Page-level top/bottom breathing room for empty state                 |

Exceptions:

- PageHeader: `px-6 py-4` (24px horizontal, 16px vertical) — matches existing `page-header.tsx` pattern exactly.
- Kebab trigger button: 32px touch target minimum (size-8) — matches `PostCardSkeleton` kebab sizing.
- Room card padding: `p-4` (16px all sides) — matches `room-card-skeleton.tsx` in RESEARCH.md.

## Color

All values sourced from `apps/web/app/globals.css` `:root` (default UniShare light theme). The design system is multi-theme; all color references must use CSS custom properties, never raw hex.

| Role            | CSS Variable            | Light Value | Usage                                        |
| --------------- | ----------------------- | ----------- | -------------------------------------------- |
| Dominant (60%)  | `--background`          | `#f7f3ee`   | Page background, sidebar, muted surfaces     |
| Secondary (30%) | `--card`                | `#ffffff`   | Room cards, PageHeader, popovers, modal      |
| Accent (10%)    | `--primary` / `--amber` | `#d97706`   | Specific reserved elements only (see below)  |
| Destructive     | `--destructive`         | `#dc2626`   | Delete confirmation dialog, delete menu item |

Accent (`--primary` / `--amber` / `--amber-subtle`) reserved for:

1. "New Board" primary Button (bg-primary text-primary-foreground)
2. Sidebar "Boards" nav item active state (bg-sidebar-accent text-sidebar-primary)
3. Mobile nav "Boards" tab active indicator
4. Focus ring (`--ring`) on interactive inputs in create-room modal
5. Visibility badge for OPEN rooms (bg-amber-subtle text-amber-foreground)

Accent is NOT used for: card hover states, kebab trigger, date meta text, or the empty state illustration background.

Visibility badge color mapping:

- OPEN: `bg-amber-subtle text-amber` (warm amber — open/public)
- VIEW_ONLY: `bg-muted text-muted-foreground` (neutral — read-only)
- PRIVATE: `bg-muted text-foreground` (strong neutral — locked)

Untitled room title fallback: `text-text-muted` (`--text-muted: #8a837e`) — per CONTEXT.md decision.

## Interaction Contract

### Room Card

**Anatomy:**

```
┌─────────────────────────────────────┐
│ [Title or "Untitled"]        [⋮]   │
│ [OPEN badge]                        │
│ Created X ago · Updated X ago       │
└─────────────────────────────────────┘
```

- Card body click: navigate to `/canvas/[slug]`
- Card border: `border border-border` with `rounded-[6px]` (matches `--radius: 6px`)
- Card background: `bg-card`
- Card hover: `hover:bg-card-dark` (`--card-dark: #f0ebe4`) — subtle warm tint, no shadow lift
- Kebab trigger (`⋮`): `size-8` button, `opacity-0 group-hover:opacity-100 focus-within:opacity-100 [@media(hover:none)]:opacity-100` — always visible on touch devices
- Card has `group` class to coordinate hover state

**Kebab menu items (in order):**

1. Open board (navigates to `/canvas/[slug]`)
2. Copy link (clipboard write + toast "Link copied")
3. Rename (opens rename Dialog)
4. Change visibility (inline RadioGroup in dropdown: OPEN / VIEW_ONLY / PRIVATE)
5. `DropdownMenuSeparator`
6. Delete (opens ConfirmDialog — styled destructive)

### Create Room Modal

- Title: "New Board"
- Single optional Input: placeholder `"Untitled board"`, label "Title (optional)"
- CTA button: "Create board" (primary, full width at bottom of modal)
- Cancel: text/ghost button or Dialog close
- On submit: POST /rooms, then router.push to `/canvas/[slug]`
- On error: keep modal open, show `toast.error(message)`
- Input is pre-focused on modal open (autoFocus)

### Rename Dialog

- Separate Dialog (not nested in DropdownMenu to avoid Radix focus conflict)
- Title: "Rename board"
- Single Input: pre-populated with current title (or empty if untitled)
- CTA: "Save name" (primary)
- Cancel: ghost button
- On save: PATCH /rooms/:slug with `{ title }`, optimistic update, rollback on error with `toast.error`

### Delete Confirmation

Uses existing `ConfirmDialog` component:

- Title: "Delete this board?"
- Description: "This cannot be undone."
- Confirm button: destructive variant, label "Delete"
- Cancel button: ghost
- On confirm: DELETE /rooms/:slug, remove card from list

### Empty State (Hero)

- Container: `flex flex-col items-center justify-center py-12 text-center gap-6`
- Inline SVG illustration: depicts a blank canvas/drawing board with a simple pen/cursor
  - All fill/stroke values use `currentColor` or CSS vars (`var(--border)`, `var(--primary)`, `var(--muted-foreground)`)
  - SVG width: 120px, height: 100px (fixed, not responsive — decorative)
  - SVG `aria-hidden="true"`
- Headline: `"No boards yet"` — `text-base font-semibold text-foreground`
- Sub-copy: `"Create a board and start collaborating with your classmates."` — `text-sm text-muted-foreground`
- CTA: "New Board" Button (primary variant) — opens same CreateRoomDialog

## States Required

For each interactive surface, all states must be implemented:

### Room Card

- Default: border-border bg-card
- Hover: bg-card-dark (warm tint)
- Loading: RoomCardSkeleton (3 skeletons while fetching)
- Empty: BoardsEmptyState hero
- Error: `toast.error` for action failures; list re-fetches via React Query invalidation

### Create Room Dialog

- Idle: input empty, submit enabled
- Submitting: submit button disabled + loading spinner (Button `disabled` + Loader2 icon)
- Error: toast shown, modal stays open, input re-enabled

### Kebab Actions

- Optimistic update (rename, visibility): local state updates immediately, rollback on error
- Delete: non-optimistic (wait for 204 before removing card)

### Page

- Auth loading: show skeleton list (3 RoomCardSkeleton)
- Data loading: show skeleton list
- Data loaded + rooms: show grid
- Data loaded + no rooms: show BoardsEmptyState
