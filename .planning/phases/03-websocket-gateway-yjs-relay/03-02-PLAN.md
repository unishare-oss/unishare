**Create `apps/api/src/modules/collab/collab.gateway.integration.spec.ts`**

This test boots a real NestJS app with IoAdapter, then uses `socket.io-client` to connect and verify relay behavior. Auth and room-existence checks are mocked at the module level to avoid needing a real database and real sessions.

**Setup pattern:**

```typescript
import { Test, TestingModule } from '@nestjs/testing'
import { INestApplication } from '@nestjs/common'
import { IoAdapter } from '@nestjs/platform-socket.io'
import { io, Socket as ClientSocket } from 'socket.io-client'
import * as Y from 'yjs'
import { CollabGateway } from './collab.gateway'
import { CollabRoomService } from './collab.room.service'
import { CollabRepository } from './collab.repository'
```

**beforeAll:**

1. Create a test module using `Test.createTestingModule` with:
   - `providers: [CollabGateway, CollabRoomService, { provide: CollabRepository, useValue: mockRepository }]`
   - Mock `CollabRepository.findBySlug` to return `{ id: '1', slug: 'test-room' }` for slug `'test-room'` and `null` for everything else
2. Mock `auth.api.getSession` at the module level using `jest.mock('@/auth/auth.config')`:
   - By default, return `{ user: { id: 'user-1', name: 'Test User' }, session: { id: 'sess-1' } }` for any cookie containing `better-auth.session=valid`
   - Return `null` for missing/invalid cookies
3. Create the NestJS app: `module.createNestApplication()`
4. Set adapter: `app.useWebSocketAdapter(new IoAdapter(app))`
5. `await app.listen(0)` — random port
6. Extract port: `const addr = app.getHttpServer().address(); port = typeof addr === 'string' ? 0 : addr.port`

**Helper function — connectClient:**

```typescript
function connectClient(opts: { cookie?: string } = {}): ClientSocket {
  return io(`http://localhost:${port}/collab`, {
    transports: ['websocket'],
    extraHeaders: {
      cookie: opts.cookie ?? 'better-auth.session=valid-token',
    },
  })
}
```

**afterAll:** `await app.close()` — this closes the server and all sockets.

**afterEach:** Disconnect any clients created during the test to prevent hanging connections.

**Test cases:**

**Test 1: "relays yjs-update to other clients in same room"**

- Connect clientA and clientB with valid cookies
- Both emit `'join-room', 'test-room'`
- Wait for both to receive `'room-joined'` event
- Set up clientB listener for `'yjs-update'`
- clientA emits `'yjs-update', Buffer.from([1, 2, 3])`
- Assert clientB receives the update as an ArrayBuffer/Buffer with bytes `[1, 2, 3]`
- Use `done()` callback or wrap in a Promise with timeout

**Test 2: "does NOT relay yjs-update to client in different room"**

- Mock `findBySlug` to also return a room for slug `'other-room'`
- Connect clientA (joins `'test-room'`), clientB (joins `'other-room'`)
- Wait for both `'room-joined'` events
- Set up clientB listener for `'yjs-update'` — if called, fail the test
- clientA emits `'yjs-update', Buffer.from([4, 5, 6])`
- Wait 500ms, then assert clientB's listener was NOT called
- Use `jest.fn()` for the listener and check `expect(listener).not.toHaveBeenCalled()` after a `setTimeout`

**Test 3: "new joiner receives full Y.Doc state"**

- Connect clientA, join `'test-room'`
- clientA emits a yjs-update (create a Y.Doc locally, make a change, `Y.encodeStateAsUpdate(doc)`, emit that buffer)
- Wait briefly for server to process
- Connect clientB, join `'test-room'`
- clientB receives `'room-joined'` with `{ slug: 'test-room', state: Buffer }`
- Apply the received state to a new local `Y.Doc` via `Y.applyUpdate(newDoc, new Uint8Array(state))`
- Assert the new doc contains the data that clientA wrote

**Test 4: "rejects connection without valid session cookie"**

- Connect a client with NO cookie: `connectClient({ cookie: '' })`
- Listen for `'connect_error'` event
- Assert the error message contains `'Unauthorized'`
- Verify the socket is NOT connected (`socket.connected === false`)

**Important implementation notes:**

- Use `Promise`-based patterns or `done()` callbacks for async socket events
- Add reasonable timeouts (5s) to prevent tests from hanging
- Set Jest timeout to 15000ms for the describe block: `jest.setTimeout(15000)`
- Each test should create its own clients and clean them up
- Use `await new Promise(resolve => setTimeout(resolve, 100))` for brief waits between operations to let the server process events
- The mock for `auth.api.getSession` should check the cookie header: if it contains `better-auth.session=valid`, return a session; otherwise return null. Use different user IDs for different clients by varying the cookie value (e.g., `valid-token-1` vs `valid-token-2` both match the `valid` substring check)
